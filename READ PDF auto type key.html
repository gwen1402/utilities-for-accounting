Nhập hóa đơn PDF vào Bảng kê

Đọc PDF → Groq AI trích xuất → điền vào sheet BANG KE HD của file KHO TỔNG. Mọi thứ chạy trên máy bạn, chỉ gửi nội dung hóa đơn tới Groq.

① Groq API

Key lưu trong trình duyệt của bạn (localStorage). Trang tự chọn model đang có trên tài khoản của bạn.

② File Excel (KHO_TỔNG_CPT_40_HL.xls)

Chưa nạp. Có thể bỏ qua và dùng nút "Sao chép để dán".

③ Hóa đơn PDF
